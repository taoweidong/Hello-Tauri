# Spec Delta

## Purpose

提供本机 Windows 环境的只读探测能力（系统概要、环境变量、磁盘、网络），供环境
检测页与后续功能消费；探测确定性完成、无副作用、浏览器模式有等价模拟。

## ADDED Requirements

### Requirement: 系统概要探测

系统 SHALL 提供只读的系统概要探测，返回操作系统版本、架构、主机名、当前用户名、
应用数据根路径等概要字段。

#### Scenario: 桌面模式获取系统概要

- **WHEN** 桌面模式发起系统概要探测
- **THEN** 返回的概要对象中各字段为非空的真实本机信息

#### Scenario: 浏览器模式获取系统概要

- **WHEN** 浏览器（web Bridge）模式发起系统概要探测
- **THEN** 返回结构与桌面模式一致、内容为明确标注的模拟数据

### Requirement: 环境变量按名读取

系统 SHALL 支持按名称读取进程环境变量的值；读取不存在的变量返回空结果而
不报错。

#### Scenario: 读取存在的环境变量

- **WHEN** 按名称读取一个当前进程已设置的环境变量
- **THEN** 返回该变量的当前值

#### Scenario: 读取不存在的环境变量

- **WHEN** 按名称读取一个不存在的环境变量
- **THEN** 返回空值，不产生错误

### Requirement: 磁盘与网络探测

系统 SHALL 提供磁盘分区（盘符、容量、可用空间）与网络适配器（名称、启用状态、
IPv4 地址）的只读枚举探测。

#### Scenario: 枚举磁盘分区

- **WHEN** 发起磁盘探测
- **THEN** 返回本机分区清单，每项含盘符、总容量与可用空间

#### Scenario: 枚举网络适配器

- **WHEN** 发起网络适配器探测
- **THEN** 返回适配器清单，每项含名称、启用状态与 IPv4 地址（无地址时该字段为空）

### Requirement: 探测确定性完成

每项探测 MUST 永不 reject：一切异常折叠为包含失败原因的确定结果；且 MUST 受
硬超时约束，超过预算时以超时结果完成，不挂起调用方。

#### Scenario: 宿主能力异常

- **WHEN** 底层宿主调用抛出异常
- **THEN** 探测返回带失败原因的失败结果，不向调用方抛出异常

#### Scenario: 探测超时

- **WHEN** 探测超过硬超时预算仍未返回
- **THEN** 探测以超时结果确定性地完成

### Requirement: 探测只读无痕

探测 MUST NOT 修改系统状态，MUST NOT 向应用数据根写入任何文件。

#### Scenario: 探测无副作用

- **WHEN** 连续执行系统概要、环境变量、磁盘、网络探测各一次
- **THEN** 应用数据根内容不变，且各探测可重复执行、结果可用于比对
